Hi, I recently pushed an update to ghosts.json in PhasOverlay-data that made the "Late" hunt option completely redundant. The reason this change was made is because all ghosts can technically hunt late, so the button just made no sense. And worse, it could actively rule out ghosts for no reason if you select it, which harms the usability of the overlay. By pushing this update, the button now does nothing on all current versions of PhasOverlay Desktop. The web version has been updated to remove the button, and the next version of PhasOverlay Desktop will remove the button too.

So again, all ghosts have the "late" hunt tag, so the late button now does anything. Your overlay is not broken, this is **intended** behaviour 

## Now, speaking on the next update

I just want to say work on the next update started a little bit ago, and the update has since evolved to be bigger than initially I expected it to be. The update will focus heavily on just improving the overlay, improving performance, streamlining UI, improving tap to speed and adding more ghost information to work with. It will basically be the same overlay, just feel a lot better to use, with more ways to customise the overlay to your liking. 

The reason for this update stemmed from the fact my friend was very confused with how the overlay works, which made me realise I may have designed it to be obvious to myself, but not everyone else. It should feel good to use regardless of your Phasmophobia skill level, with features for pros to take advantage of. I hope to have a preview of the update out in the next few weeks, but I need to spend more time with it before that. See you soon!
