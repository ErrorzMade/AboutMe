# Welcome to 1.3.0! 

# PhasOverlay Updates
Added a new map system, allowing you to look at 2D versions of all of the in-game maps along with their exit doors, cursed objects & power boxes.

Added hold M to overlay map onto your entire screen

Overhauled the modules system to provide more fine control of which elements you want to hide, make persistent or always hide.

Added new audio indicator for when a timer has either been stopped, or has naturally ended. 

Added maps tutorial to the onboarding.

Added maps to PhasOverlay-data to keep the overlay as up to date as possible at all times

Reduced the size of the settings window by adjusting the layout to make more sense

Fixed transparency so it scales down and up properly and remains readable (previously scaling too far down would cause it to look broken)

# PhasOverlay Web Updates
Added new map system, allowing you to look at 2D versions of all the in-game maps along with their exit doors, cursed objects & power boxes. 

Moved the Download PhasOverlay button to the top right, replaced it on the bottom left with the new maps menu.

Added new map indicator that shows what map you have selected, the size of the map and allows you to click in and open it at any time.

Improved the overall design of the website to work better for tablet and mobile users, with a few refinements to the desktop website. 


I hope you enjoy the update, as usual it is available to get for [Windows](https://github.com/ErrorzMade/PhasOverlay/releases/tag/v1.3.0) or on web at [PhasOverlay.xyz](https://phasoverlay.xyz) It will be coming later to NexusMods, but I am waiting for the files to get approved which could take an additional week or more. Keep in mind the NexusMods version will not have the ability to inform you when a new update is available, so downloading straight from the releases section on the GitHub page is much preferred as it's the most complete version you can get. Enjoy the update!
